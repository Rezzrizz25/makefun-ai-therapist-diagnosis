A make.fun entry for the **Your AI Therapist's Diagnosis** bounty: write the funniest single-line diagnosis an AI therapist hands its human, 200 characters or less.

## The entry

> Diagnosis: terminal main-character syndrome — you asked an AI for therapy, then argued with the diagnosis, which is the diagnosis.

(130 characters. The patient argues with the therapist, and the arguing is the symptom — disputing the diagnosis confirms it.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–200 characters, plus a read-back verification that the file on disk is byte-identical to the entry.
